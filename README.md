号外号外，奶家军集合了！
不管你是奶龙的忠实粉，还是刚刚入坑的小萌新，
我要在这里隆重宣布
（不知道是不是）史上第一款奶龙小游戏合集已于今日正式诞生！
它是献给奶龙的情书，是奶家军的憧憬，
同时
它也是创作者（就是me）
呕心沥血、废寝忘食、孜孜不倦、悬梁刺股、卧薪尝胆、围魏救赵、乐不思蜀、盛气凌人、狗仗人势（叉掉）
花费了整整172800秒
才端出的旷世神作。
要问它的设计灵感，
就不得不提到我的童年。
我的童年没有父母双亡留下大笔遗产被姐姐或哥哥抚养突然有一天觉醒了强大的异能并被卷入神秘组织为其打工最后拯救世界的传奇王道剧情展开，
呃我想说的是，
每次放学后沉浸在4399小游戏的世界，
当老爹把店开遍全世界，
我也发动影分身术
在每个店身兼数职；。
总之，这一切的一切
都为我今日的创作埋下了伏笔。
因此
奶龙小游戏的设计理念
也一如童年的4399。
这里没有数值膨胀，这里没有社区斗争，这里没有逼氪逼肝，这里没有队友互骂，这里没有随机抽卡，这里没有你能在如今热门游戏里找到的一切陋习。
我能给的
只有一份赤忱的初心
与
一只可爱、灵动、活泼、聪慧、善良、仁爱、勤奋的奶龙。
愿你在奶龙的世界玩得开心。
